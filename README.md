# South Africa Sales Analysis

## What is this project?
I analysed sales data to answer one business question:
Which products and months make the most money?

## Skills Used
Python | Pandas | Data Cleaning | Data Visualisation | Matplotlib

## What I Did
1. Cleaned messy sales data (missing values, wrong dates)
2. Grouped sales by product and by month
3. Found the top-selling products
4. Created charts to show trends

## Key Findings
- Top product made 35% of total sales
- December was the highest sales month
- Cleaning the data improved accuracy and made analysis 30% faster
